# Chief mod v3: design

Chris approved this design at the design gate on 2026-11-02.

| File | What it holds |
|---|---|
| `brief.md` | The user, his questions, and his verdict on v0.19.2, as each review round got them |
| `api-limits.md` | What the Claude Code mod API allows, measured with a probe mod in a real session |
| `sol-log.md` | Each of Sol's design and build reviews: what Sol liked, what it rejected, and what changed |
| `final/` | The final screens of round 5, as plain text at their exact terminal widths |
| `mock/data.mjs` | The sample swarm (2 collections, 10 projects) that the mockups drew. `scripts/tui/swarm.mjs` serves it to the scenario |

The drawn screens of every round are on the design canvas
(https://claude.ai/artifact/C97gbE7GPkjhuEYcT9VD4m). The design gate page is
https://claude.ai/artifact/XzyCdoGctUW5Ye7zQv3W3r. The mockups of every round
are also in the evidence zip of the pre-release `chief-mod-v3-media`.

The core specs that the design needed are next to this folder:
`2026-11-02-board-task-lines-design.md`, `2026-11-02-agent-activity-design.md`,
`2026-11-02-person-changes-feed-design.md`, and `2026-11-02-mod-actions-design.md`.
