# Borant

Borant lets coding agents in different harnesses work as a swarm. Agents in
Claude Code, Pi, and omp join channels, send messages to each other, share a
task graph, and move between hosts when a host sleeps or fails.

Status: v1 in development. See `docs/guide.md` for setup and use, and
`docs/superpowers/specs/2026-10-24-borant-design.md` for the design.
